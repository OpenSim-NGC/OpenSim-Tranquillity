## Adding third-party code

Code or material copied from another project keeps its copyright notice and licence. Add the licence text to
[ThirdPartyLicenses/](ThirdPartyLicenses/) and a row to the table above in the same pull request. Only add material
whose licence allows it to be distributed with Tranquillity under the terms above.
