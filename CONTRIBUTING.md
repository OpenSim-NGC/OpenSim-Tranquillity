# Contributing

Thank you for helping with Tranquillity.

- Start with [HUMANS.md](HUMANS.md): setting up, branches, the life of a change and working with an AI agent.
- The code is mapped in [ARCHITECTURE.md](ARCHITECTURE.md). AI coding agents must also follow
  [AGENTS.md](AGENTS.md).
- Report bugs as [issues](https://github.com/OpenSim-NGC/OpenSim-Tranquillity/issues), following
  [Docs/BUG_REPORTING.md](Docs/BUG_REPORTING.md). Ask questions in
  [Discussions](https://github.com/OpenSim-NGC/OpenSim-Tranquillity/discussions).
- Report security problems privately, as [Docs/SECURITY.md](Docs/SECURITY.md) explains.

Pull requests target `develop`, cover one issue or task, use the
[template](.github/pull_request_template.md), and come with tests ([Docs/TESTING.md](Docs/TESTING.md)): a bug fix
includes a test that fails without it. CI must pass before a maintainer merges.
